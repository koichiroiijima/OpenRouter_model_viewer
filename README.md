# OpenRouter モデル料金比較

OpenRouter の公開 API から最新のモデル料金と性能指標を取得し、一覧・比較・散布図で確認できる静的 Web ページです。

## 必要なもの

- ブラウザのみ（Chrome / Firefox / Edge など）
- Python 3（ローカルサーバ起動用。既に別の HTTP サーバがあれば不要）

インストール作業は不要です。

## 起動方法

1. 起動スクリプトを実行（既定ポート 8001）:

   ```bash
   scripts/start.sh
   ```

   ポートを変えたい場合は環境変数 `PORT` を指定します:

   ```bash
   PORT=8000 scripts/start.sh
   ```

2. ブラウザで <http://localhost:8001> を開く

3. 停止するとき:

   ```bash
   scripts/stop.sh
   ```

> スクリプトを使わず `python3 -m http.server 8001` を直接実行しても構いません。
>
> 変更が反映されない場合はハードリロード（`Ctrl+Shift+R`）してください。

## 操作方法

### 左ペイン（モデル候補リスト）

| 操作 | 内容 |
|---|---|
| 検索ボックス | モデル名・ID で絞り込み |
| 列見出しクリック | ソート（昇順⇄降順）。初期は「提供開始」の新しい順 |
| チェックボックス | 比較・散布図に追加するモデルを選択 |
| 「性能KPI有りのみ」 | Coding / Intelligence / Agent の 3 指標を持つモデルのみ表示 |
| 「価格有りのみ」 | 入力・出力価格を持つモデルのみ表示 |

### 右ペイン(比較表）

チェックしたモデルだけが表示されます。列見出しクリックでソートできます。

各価格列で最安値のモデルに ✓ マークを付けてハイライトします。

### 指標散布図（ページ下部）

選択モデルを X/Y 軸でプロットします。軸の指標はプルダウンで変更でき、料金軸は自動的に対数スケールになります。

## 表示内容について

- **単位**: 料金は USD / 100万トークン
- **データ源**: `GET https://openrouter.ai/api/v1/models`（ページ読み込み時に毎回取得するため常に最新。2026-09 時点で約458モデル）
- **「—」表示**: 指標・価格のデータがない項目
